# raw/

Contexto que no sale del código: notas de conversación, decisiones informadas,
antecedentes. Es el único lugar de `wonk-docs` que se llena a mano y que no
depende de un archivo de código para existir.

Regla: si un hecho sí tiene origen en el código, ese hecho va en `runtime/` o
`wiki/` citando la ruta; aquí no se copia.
